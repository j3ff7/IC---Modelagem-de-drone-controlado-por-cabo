# PX4 workspace local

Esta pasta e reservada para a integracao incremental com PX4.

O clone local do PX4 fica em:

```text
px4/PX4-Autopilot/
```

Esse diretorio e ignorado pelo Git deste repositorio para evitar versionar o PX4 inteiro dentro do projeto do tethered drone. A versao usada deve ser registrada na documentacao do projeto, com remote, tag, branch e commit.

Baseline PX4 inicial:

```text
remote: https://github.com/PX4/PX4-Autopilot.git
tag:    v1.14.4
commit: 1555f2bd2229544c43966ab5f94879c41d8e1e01
modelo: gz_x500
```
